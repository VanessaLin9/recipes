## 使用與更新方式

- 一道食譜一個 Markdown 檔案，放在 `recipes/`；材料、做法、心得與試做紀錄放在一起。
- 不清楚的用量或步驟保留待確認，不自行補成定案；原筆記沒寫的做法也不默補。
- 不同顏色的份量或配方先並列，不預設紅字一定是最新定稿。已知滷肉飯的紅字「多少 cc？」是其他讀者的提問。
- 匙量統一寫「大匙／小匙」：1 大匙 = 15 ml，1 小匙 = 5 ml。原筆記 `tbsp / tp` 統一為大匙，`tsp / sp / t` 統一為小匙；手寫縮寫依有克數對照的記錄判讀，非新增實測結果。
- 「鹽匙」「鐵湯匙」「平匙」等器具描述與大小不明的「匙」保留，不擅自換算；克數與匙量若原本不一致，保留待確認。`cc` 與 `ml` 都依來源保留。
- 食材名稱統一使用「油蔥酥」；來源的不同用字可另註。
- 試做後補記日期、實際材料量、操作與口感；回報日期與製作日期不同時分開註明。
- 新增或更名食譜時，一起更新本頁索引及[原筆記頁碼對照](原筆記頁碼對照.md)。
- 原始 PDF、頁面圖片均不隨這次整理上傳。原 PDF 僅在本機保留，並由 `.gitignore` 排除。
