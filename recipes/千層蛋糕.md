# 千層蛋糕

標籤：甜點

來源：私人手寫筆記第 23 頁（原始 PDF 僅保留於本機）

狀態：依原筆記電子化；未記錄及辨識不明處另列待確認。

## 材料
- 低筋麵粉 120 ml（原單位為 ml，尚未換算成 g）。
- 玉米澱粉 23 g。
- 牛奶共 376 ml，分兩次各 188 ml。
- 植物油 45 ml。
- 蛋 4 顆。
- 砂糖 45 g。

## 做法
1. 低筋麵粉、玉米澱粉與第一份牛奶 188 ml 混勻。
2. 加入植物油；依原頁箭頭，這組混合物後續加入蛋液。
3. 蛋與砂糖打勻，再加第二份牛奶 188 ml 打勻。
4. 合併兩組混合物。

## 待確認
- 麵粉的 ml 是否誤記，以及混合順序。
- 煎皮、夾餡、組裝與冷藏方式均未記錄；目前是麵糊筆記。
