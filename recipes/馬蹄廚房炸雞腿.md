# 馬蹄廚房炸雞腿

標籤：雞肉、油炸

來源：私人手寫筆記第 29 頁（原始 PDF 僅保留於本機）

狀態：依原筆記電子化；未記錄及辨識不明處另列待確認。

## 材料版本
| 材料 | 2 隻雞腿（黑字，含紅字修正） | 3 隻雞腿（綠字） |
| --- | --- | --- |
| L 型雞腿 | 2 支 | 3 支 |
| 鹽 | 少許，灑表面 | 未另記 |
| 糖 | 2 g | 3 g |
| 白胡椒粉 | 可多些，兩面灑 | 未另記 |
| 五香粉 | 2～3 g | 3～4.5 g |
| 醬油（美極） | 適量 | 未另記 |
| 洋蔥、蒜頭 | 適量 | 未另記 |
| 玉米澱粉 | 1 小匙 | 1.5 小匙 |
| 中筋麵粉 | 20 g（紅字修正，取代原記 3 小匙） | 25 g |
| 蛋液 | 2 顆蛋的蛋液 | 未另記 |

## 做法
1. 雞腿加鹽、糖、白胡椒、五香粉、醬油按摩。
2. 加洋蔥、蒜頭，再按摩。
3. 加玉米澱粉、麵粉，拌勻。
4. 加蛋液按摩。
5. 油溫 150°C 炸 4 分鐘，再以 180°C 炸 2 分鐘。
